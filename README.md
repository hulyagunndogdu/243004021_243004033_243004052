# HASTANE RANDEVU SİSTEMİ

Bu proje, C# Windows Forms ve SQL Server kullanılarak geliştirilmiş bir hastane randevu sistemi uygulamasıdır.

## Proje Özellikleri
- Randevu oluşturma ve iptal etme
- Doktora yorum yapma ve puan verme
- Doktor profil ve yorumlarını görüntüleme
- Doktor ekleme, düzenleme ve silme işlemleri
- Hastane istatistiklerini görüntüleme

## Kullanılan Teknolojiler
- C#
- Windows Forms
- SQL Server
- ADO.NET

## Veritabanı
Veritabanı oluşturmak için hastane_randevu_sistemi.sql dosyasını çalıştırmanız yeterlidir.
